## Orden sugerido de la conversación

1. **Saludo y contexto** — empresa G12, urgencia de viáticos, rol del alumno.
2. **Estado real** — módulo avanzado; pilotos OK; pendiente transición.
3. **Estado académico** — TAP existe pero hay que alinearlo a `Estructura_TAP.pdf`.
4. **Lo que se propone cimentar ahora** (ver `escritorio/puntos-a-proponer.md`):
   - Metodología cascada + ágil → híbrido documentado.
   - Arquitectura web + app + API + BD + OCR + notificaciones.
   - Revisión capítulo por capítulo del TAP.
5. **Pedir feedback** — ¿priorizar marco teórico, desarrollo o anexos (RF/UML/ER)?
6. **Cierre** — próximos entregables académicos y fecha de revisión.
