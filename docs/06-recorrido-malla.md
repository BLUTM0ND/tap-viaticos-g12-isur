# Recorrido malla DSI ↔ TAP

Relación sugerida entre cursos de la malla de **Desarrollo de Sistemas de Información** (ISUR) y capítulos/anexos del TAP. Ajustar con el PDF de malla en `docs/fuentes/` cuando esté disponible.

| Área formativa | Aporte al TAP | Capítulo / anexo |
|----------------|---------------|------------------|
| Fundamentos de programación / POO | Lógica app Android, API | 5 Desarrollo |
| Base de datos | Modelo ER, integridad, consultas | 4 Intro (marco) + 5 + Anexo ER |
| Ingeniería de requisitos | RF/RNF, casos de uso | 4 Diagnóstico/objetivos + Anexo RF |
| Análisis y diseño (UML) | Casos de uso, secuencias, componentes | 5 + Anexos UML |
| Ingeniería de software / metodologías | Cascada, ágil, híbrido | 5a Metodología |
| Arquitectura de software | Capas web+móvil+API+BD+OCR | 5 + `docs/09` |
| Desarrollo web | Panel PHP | 5 Desarrollo |
| Desarrollo móvil | App Android | 5 Desarrollo |
| Calidad / pruebas | Casos de prueba, pilotos | 5 Resultados |
| Gestión de proyectos / implantación | Transición, capacitación | 5 + 6/7 Conclusiones/Recomendaciones |
| Ética / redacción académica | Referencias, citas, estructura formal | 3 Resumen, 9 Referencias |

## Cómo usarlo en la reunión

- Mostrar que el TAP **integra** competencias de la malla, no es un anexo aislado.
- Si la asesora pide “cimentar”, señalar metodología + arquitectura + revisión estructural como puente malla→informe.
